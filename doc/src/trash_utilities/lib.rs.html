1//! # Trash Utilities
2//!
3//! A high-performance Rust library providing comprehensive async, threading,
4//! memory management, and utility functions for building efficient applications.
5//!
6//! ## Features
7//!
8//! - **Async Operations**: High-performance async utilities with smol, futures-lite, and crossfire
9//! - **Threading**: Parallel processing with `fork_union` and work-stealing schedulers
10//! - **Memory Management**: Efficient allocation with mimalloc and custom memory pools
11//! - **Channels**: Advanced channel communication with monitoring and serialization
12//! - **System Utilities**: Time handling, environment variables, file system operations
13//! - **Data Processing**: Parsing, serialization, and data manipulation
14//! - **I/O Operations**: File and network I/O with async support
15//! - **Logging**: Structured logging
16//! - **Utilities**: Compression, hashing, JSON handling, and more
17//!
18//! ## Quick Start
19//!
20//! ```rust
21//! use trash_utilities::*;
22//!
23//! // Spawn an async task
24//! spawn_task!("my_task", async {
25//!     println!("Hello from async task!");
26//!     Ok(())
27//! });
28//!
29//! // Parallel processing
30//! let data = vec![1, 2, 3, 4, 5];
31//! let result = parallel_map(data, |x| x * 2);
32//!
33//! // Memory operations
34//! let ptr = alloc_from_pool!("default", 1024);
35//!
36//! // System utilities
37//! let now = current_utc_time();
38//! let home = read_env_var("HOME").unwrap_or_default();
39//! ```
40//!
41//! ## Modules
42//!
43//! - `async`: Comprehensive async utilities
44//! - `channels`: Advanced channel communication
45//! - `chars`: Character and string processing
46//! - `common`: Shared utility functions
47//! - `data`: Data parsing and serialization
48//! - `io`: I/O operations
49//! - `logging`: Structured logging
50//! - `macros`: Ergonomic macros
51//! - `memory`: Memory management and pools
52//! - `serde`: Serialization utilities
53//! - `sys`: System utilities
54//! - `parallel`: Threading and parallelism
55//! - `utils`: Additional utilities
56//!
57//! ## Re-exports
58//!
59//! Key functions and types are re-exported at the crate root for convenience:
60//!
61//! - `spawn_task!`, `parallel_map!`, `alloc_from_pool!` from macros
62//! - `current_utc_time`, `read_env_var` from sys
63//! - `parallel_map`, `parallel_for_each` from threads
